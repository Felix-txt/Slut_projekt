CS - Clicker Game

Ett adhd spel man klickar på click för att få pengar som man sedan kan spela med för att få skins.

Du kan uppgradera dina clicks och du kan låsa upp nya lådor som man får skins ifrån.

Spelet har inget mål utan det är bara att köra och se hur långt du kan komma och hur många sällsynta skins du kan få.
